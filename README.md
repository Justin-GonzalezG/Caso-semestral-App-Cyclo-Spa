# MyCiclo | EVA

## Descripción del proyecto

MyCiclo | EVA es un proyecto de aplicación móvil orientado al seguimiento del ciclo menstrual y la gestión de la fertilidad femenina. Busca ofrecer una experiencia digital intuitiva que permita a las usuarias registrar información, consultar datos y comprender mejor el seguimiento de su ciclo.

La aplicación se relaciona con el dispositivo EVA, que permite observar patrones de cristalización de muestras de saliva mediante un microscopio, transformando estas observaciones en información visual de apoyo.

## Objetivo

Desarrollar una aplicación móvil que facilite el seguimiento del ciclo menstrual, la organización de información personal y la visualización de datos relacionados con la fertilidad, considerando los requisitos funcionales y de usabilidad definidos para el proyecto.

## Funcionalidades de la aplicación

- **Registro y perfil de usuario:** gestión de la información personal.
- **Seguimiento del ciclo menstrual:** organización y consulta de información relacionada con el ciclo.
- **Bitácora personal:** registro y revisión de observaciones y actividades.
- **Visualización de información:** presentación de datos mediante una interfaz clara y organizada.
- **Navegación entre secciones:** acceso a las distintas funcionalidades de la aplicación.
- **Experiencia de usuario:** diseño visual personalizado, componentes interactivos y una interfaz intuitiva.

## Tecnologías utilizadas

- **Kotlin:** lenguaje de programación.
- **Jetpack Compose:** desarrollo declarativo de interfaces para Android.
- **Android Studio:** entorno de desarrollo.
- **Room:** almacenamiento local de información, según la implementación.
- **Gradle:** gestión de dependencias y compilación.
- **Git y GitHub:** control de versiones y gestión del código fuente.
